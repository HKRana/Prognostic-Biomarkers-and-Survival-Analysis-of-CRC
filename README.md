### This code is for the identification of prognostic biomarkers, survival analysis, and validation

##
**Prognostic Biomarkers and Survival Analysis:**
1. The file "Prognostic_Biomarkers_and_Survival.R" is for the identification of prognostic biomarkers and survival analysis of those biomarkers
2. Two datasets are required to run the code: </br>
     I. [coadread_tcga_pan_can_atlas_2018_clinical_data.csv](https://drive.google.com/drive/u/1/folders/1ld7jrUADl9o7cMsZr9IjEVUZLZed1qIi) </br>
     II. [data_mrna_seq_v2_rsem_zscores_ref_all_samples.csv](https://drive.google.com/drive/u/1/folders/1ld7jrUADl9o7cMsZr9IjEVUZLZed1qIi)
3. The code will provide a list of prognostic biomarkers with P value, Adj. P value and logFC
4. The code will also provide survival information and survival curves of the biomarkers
##

**ROC Analysis of the Prognostic Biomarkers:**
1. The folder "Code for Validation" contains several files for the ROC analysis for the prognostic biomarkers
2. The file "ROC of the PBMs.R" is for the ROC analysis of the influential genes
